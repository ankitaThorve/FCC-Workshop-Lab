# Camper Cafe Menu ☕🍰

A simple and visually appealing cafe menu webpage created using **HTML** and **CSS** as part of the FreeCodeCamp Responsive Web Design curriculum.

## 📌 Project Overview

The **Camper Cafe Menu** project demonstrates how to structure content using semantic HTML and apply styling with CSS to create a real-world menu layout. The page features a coffee-themed background, a centered menu card, and clearly organized sections for items and prices.

## 🛠️ Technologies Used

- HTML5  
- CSS3  

## 🎨 Features

- Coffee bean background image for visual appeal  
- Center-aligned menu layout  
- Separate sections for **Coffee** and **Desserts**  
- Clean typography and spacing  
- Price alignment for better readability
