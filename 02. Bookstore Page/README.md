# XYZ Bookstore 📚

XYZ Bookstore is a simple static webpage that showcases a small collection of books with brief descriptions and call-to-action buttons. This project is built using basic HTML and is suitable for beginners learning web development fundamentals.

## 🔍 Project Overview

The webpage displays:
- A bookstore title and short introduction
- Two book listings with:
  - Book title
  - Short description
  - "Buy Now" button
- Cart and checkout action buttons

This project focuses on understanding **HTML structure**, **content hierarchy**, and **basic user interface elements**.

## 🛠️ Technologies Used

- HTML5
